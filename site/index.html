Screenlabel
How it works Privacy GitHub

macOS · local-first

Search your screenshots by what's in them.

Your screenshots folder is a graveyard of Screenshot 2026-06-12 at 4.47.13 PM.png. Screenlabel reads each one, then lets you find it by typing what you remember — "that missing API key error", "the receipt from the hardware store".

Download for macOS Universal · Apple Silicon and Intel · runs on your own OpenAI key

Your files, not a database

Every screenshot gets a plain .md file next to it, holding its description, tags, and your notes. Open them in Obsidian, grep them, sync them, move them. The index is a cache you can delete and rebuild.

Notes that are actually notes

Screenshots are where things go to be forgotten. Write on them in a full-screen Markdown editor with live preview, and the writing lands in a file you own.

Search by meaning

Descriptions and any text in the image are embedded, so searching "pricing page" finds the screenshot of a pricing table even when the words don't match. Ranking runs locally, in under a millisecond.

Drop it in and forget it

Point Screenlabel at the folder your Mac already saves screenshots to. New ones get read and filed as they appear.

What leaves your machine

One thing: the screenshots you choose to have described, sent directly from your Mac to OpenAI using your own API key. There is no Screenlabel server, no account, and no telemetry. Your key is stored in the macOS Keychain, not in the app.

You'll need an OpenAI API key. Describing a screenshot costs a fraction of a cent, billed to you by OpenAI, with no markup from us.
